# Chosen People's Church Website

**Official website for Chosen People's Church — Centre for Reconciliation & Restoration, Ibadan.**

Live: [chosenpeopleschurch.com](https://www.chosenpeopleschurch.com)

---

## What It Does

A fully SEO-optimised static website for Chosen People's Church in Challenge, Ibadan. Includes the church's full online presence: services, sermons, events, gallery, giving, and ministry information.

---

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Home — welcome, service times, about |
| `sermons.html` | Sermons archive |
| `events.html` | Upcoming events |
| `gallery.html` | Photo gallery |
| `giving.html` | Online giving / tithes |

---

## Tech Stack

- Pure HTML5 + CSS3 + Vanilla JavaScript
- Fully SEO optimised (sitemap.xml, robots.txt, OG tags, canonical URLs)
- Deployed via cPanel

---

## SEO Features

- Complete meta tags and Open Graph markup
- XML sitemap
- robots.txt
- Canonical URLs
- Optimised WebP images
